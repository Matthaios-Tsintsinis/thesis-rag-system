                                # head-on with this file's numpy>=2.1 floor.
                                # The collision was invisible for weeks because
                                # nothing imported numba; umap-learn does.
                                # Resolution is upgrading numba (>=0.66 drops
                                # the numpy<2.1 pin), NOT lowering numpy —

                                # Pulled transitively: llvmlite, pynndescent.

# REPRODUCIBILITY NOTE. UMAP output is version-sensitive even under a
# pinned random_state, so M4's tree topology is reproducible only against
# a pinned stack, not absolutely. Verified-working set, and the one to
# quote in the thesis methods section:
#   numpy 2.4.6 / numba 0.66.0 / llvmlite 0.48.0 / umap-learn 0.5.12 /
#   pynndescent 0.6.0   (Colab, Python 3.12, 2026-07-29)
#
# INSTALL ORDER IS NOT OPTIONAL — see the README's Colab block sequence
# (install, RESTART, stack check). Installing these upgrades numpy inside a live

#   ImportError: cannot import name '_center' from 'numpy._core.umath'
# and it takes down faiss / torch / sentence-transformers, not just UMAP.
# Install, RESTART THE RUNTIME, then verify. Never run an eval cell in
